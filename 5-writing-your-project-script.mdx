Once the schedule has been created, you can move on to writing the video script.

At the very top, you can add an additional language (for example: FR, IT, ES, etc.).

Below that, the colored blocks represent the structure of your script. For example: Hook, Future, Solution, Product, CTA.\
Each block can be renamed (by double-clicking the title), moved, recolored using the eyedropper tool in the bottom-right corner of each block, deleted, or duplicated.

Once everything is ready, you can write your script in the first tab: “Write”.

Then, once that’s done, you can move on to the cutting phase, which allows you to create scenes for the storyboard in the “Cutting” tab.

Simply hold left-click, drag, and release to split a sentence (and therefore create a scene). Right-click to delete a scene if needed.

Once everything is complete, you can move on to the storyboard stage.
